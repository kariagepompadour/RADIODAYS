## 1. 変わったところ

| 操作 | Stage 2-1 | Stage 2-2 |
| --- | --- | --- |
| ダイヤルを回す | 音量 | **選局**（時計回り＝次の局、反時計回り＝前の局。最後の局の次は最初の局） |
| 押しながら回す | 音量 | **音量**。離してもミュートは切り替わらない |
| 短く押して離す | ミュート | ミュート（変更なし。回さずに0.8秒以内に離した場合だけ） |
| `,`・`/`（左・右）、`P`・`N` | `N`＝次の局 | 前の局・次の局 |
| `;`・`.`（上・下） | 音量 | 音量（変更なし） |

Wi-Fi設定、NVSの保存方式（名前空間 `radiodays`、キー `wifi`）、放送局の一覧（`stations.h`）は変えていない。

## 2. 選局の仕組み（再生の安定のために）

| 仕組み | 内容 |
| --- | --- |
| 回したときの判定 | ノブが押されている間（前回の読み取りで押されていた場合も含む）と、離してから0.2秒以内の回転は**音量**。それ以外の回転は**選局** |
| 表示と接続の分離 | 画面の局名と指針は、回したらすぐに動く。再生する局を変える要求は、**ダイヤルが0.35秒止まってから**1回だけ送る。速く回して局を通り過ぎても、途中の局にはつながない |
| 要求の扱い | 要求は1つの変数に入れ、新しい要求が古い要求を上書きする。再生を担当するタスクは、接続中・バッファ中・再生中のどの段階でも要求に気づくと、今の局を閉じてから新しい局を開く |
| 同じ局に戻ったとき | 回して元の局に戻した場合は、つなぎ直さない |
| 選んだ局につながらないとき | その局のまま「NO SIGNAL - RETRY」と表示し、10秒ごとにつなぎ直す。ダイヤルを回せば、すぐに別の局へ移る |
| 起動直後の局につながらないとき | Stage 2-1と同じく、次の局へ自動で移る。指針もその局へ移る（最初に選局するまで） |
| メモリ | ストリーム用バッファとデコーダー用のメモリは、起動時に1回だけ確保して使い回す。局を開くたびに作る小さなオブジェクトは、閉じるたびに解放する。足りなければ「つながらない局」として扱い、止まらない |

## 3. 画面

| 場所 | 内容 |
| --- | --- |
| 局名・国名・CH | 指針の位置にある局（回すとすぐに変わる） |
| 目盛り（新規） | 局の数だけ目盛りがあり、選んでいる局の位置に赤い指針が立つ。Stage 3では、BCLラジオ風の目盛りと指針に置き換える |
| 曲名 | 再生中の局のもの。選局している間は消す |

| 音量・Wi-Fi・空きメモリ | Stage 2-1と同じ |

## 5. 静的確認

- ノブの判定のコードをそのまま取り出してMacでテストし、8項目すべてに合格した
  - 短く押す → ミュート
  - 押しながら回す → 音量になり、ミュートにはならない
  - 離した瞬間の回転、離して0.2秒以内の回転 → 音量
  - 押さずに回す → 選局
  - 長く押す → 何も起きない
  - 局の端での折り返し（最後→最初、最初→最後）
- Stage 2-1のフォルダのファイルは、SHA-256で変わっていないことを確かめた

## 6. 導入とテスト

導入の手順はStage 2-1と同じ（[stage-2-1.md](stage-2-1.md) 第4節）。`RadioDays_2_2.ino.bin` を導入する。

- Launcherは、新しい版を**新しい領域**に入れる（設計書 3.5.5節）。Stage 2-1の領域は残るので、空きが0x150000以上あることを確かめる
- 新しい領域の名前は `radio1` などになる見込み（`radiod` がすでにあるため）
- 「Need …」が出たら「Cancel」

**確認する項目**

| # | 確認すること | 期待する結果 |
| --- | --- | --- |
| 1 | 回して選局 | 時計回りで次の局、反時計回りで前の局。最後と最初でつながる |
| 2 | 速く回す | 途中の局につながらず、止めた局だけにつながる |
| 3 | 接続中に回す | 止まらずに新しい局へ移る |
| 4 | 押しながら回す | 音量だけが変わる。離してもミュートにならない |
| 5 | 短く押す | ミュートとその解除 |
| 6 | 元の局に戻す | つなぎ直さずに再生が続く |
| 7 | 何度も選局する | 空きメモリ（画面の最下行、シリアルの `[RADIO] open … heap …`）が減り続けない |
| 8 | Stage 2-1の項目 | Wi-Fi、再生、Wi-Fiが切れたときの復帰など（stage-2-1.md 第6節） |
