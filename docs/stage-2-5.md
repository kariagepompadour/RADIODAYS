## 1. 変更内容

| 項目 | 内容 |
| --- | --- |
| 時計 | 年月日（`2026.10.21`）と24時間表示（`23:45`、コロンが1秒ごとに点滅）。周波数の右側（x＝176〜238） |
| 時刻合わせ | Wi-Fiにつながったら、NTP（ntp.nict.jp、pool.ntp.org）で合わせる。以後、SNTPが定期的に合わせ直す |
| 時刻を合わせる前 | `----.--.--` と `--:--` を表示し、月は表示しない。**このアプリの起動中に、NTPから同期の通知を受けるまで、時刻を表示しない**（別のアプリなどが本体に残した時刻は信用しない） |
| タイムゾーン | 日本時間（`JST-9`）の定数。放送局のLocationとは別の設定で、Locationを変えても時計は変わらない |
| 月 | 実際の月齢に合わせた月の形（直径15ピクセル）。クリーム色の明るい面と暗い面。北半球（日本）から見た向き（満ちていく月は右側が明るい） |
| 月齢の計算 | SOUND TERRARIUMと同じ計算（月と太陽の離角を主な項で求める）。同じ作者のMITのコード |
| 月の描き直し | 月齢が1/64変わるとき（約11時間ごと） |
| 周波数の位置 | 周波数の数字（大きさは変えない）を、レベルメーターのすぐ右に移した。「88.7」はx＝36〜143、「MHz」は150〜167 |
| NVS | 書き込まない（SOUND TERRARIUMは時刻を保存しているが、RADIO DAYSは保存しない） |

変えていないもの：音声再生、ノイズ、選局、レベルメーター、U135、Wi-Fi。

## 3. 静的テスト（Mac上、スケッチから取り出したコード）

7項目すべてに合格した。

| テスト | 結果 |
| --- | --- |
| 2024-04-08（日食の新月） | 月齢0.001（期待値0） |
| 2024-04-15（上弦） | 0.251（期待値0.25） |
| 2024-04-23（満月） | 0.500 |
| 2025-03-14（月食の満月） | 0.501 |
| 向き | 上弦では明るい画素の100%が右側、下弦では0% |
| 新月・満月 | 新月はすべて暗く、満月はすべて明るい |
| JST | 2025-10-21 00:00 UTC → `2025.10.21 09:00` |

**参考（変更はしていない）**：SOUND TERRARIUMの月の描き方では、上弦の月の左側が明るくなる（同じテストで確認）。北半球の見え方とは左右が逆だが、意図したものかどうかはわからない。SOUND TERRARIUMには手を加えていない。
