## 2. A：公開前に必須（このままでは公開できない）

| # | 作業 | なぜ必須か | 根拠 |
| --- | --- | --- | --- |
| A1 | **ライセンスの整理** | 配布する `.ino.bin` には、GPL v3のESP8266Audioが含まれる。バイナリを配る場合はGPL v3の条件（対応するソースを入手できるようにするなど）に従う必要がある。あわせて、使っているほかの部品（Arduino-ESP32のコア、ESP-IDF、M5GFX・M5Unified・M5Cardputer、Natural Earthの地図、SOUND TERRARIUM由来の絵）の表示をまとめる。**方針を作者が決める**（例：ソースとバイナリを公開し、バイナリはGPL v3として配る） | README「ライセンス」、`stage-2-4.md` 6.5節、`development-plan.md` |
| A2 | **放送局の利用条件の確認と、収録する局の確定**（U4で85局に。途中経過は `usb-u4.md` 第7節：公式のURLと確認できたのはRNZだけ、SomaFMの直接リンクは「個人の利用だけ」） | 局のURLはバイナリとソースに入る。全27局の利用条件が未確認。NHK WORLD（WRN経由）は正式な配信かどうかも未確認。確認できない局は外すか、扱いを決める | `stations.md` 第1節 |
| A3 | **公開する版を決め、その版でWi-Fiの経路を実機で一通り確かめる** | U2a3の実機試験はUSB中継だけ。公開版の主な使い方であるWi-Fiでの再生、Wi-Fiの設定と保存、時計・月・空の窓、Locationの保存は、U2a系の版で実機の記録がない（Stage 2-5〜3-3の資料も未記録のまま） | 第1節の表 |
| A4 | **（U2a4で対応。実機は未確認）** **Wi-Fiを保存していない本体で、ラジオの画面に進めない**（USB中継を公開機能にする場合） | コードで確認した：起動画面でキーを押すと、保存したネットワークがなければ必ずWi-Fiの設定に進み、そこから戻ると起動画面に戻る（`handleStart()`・`leaveSetup()`）。作者の本体には家のWi-Fiが保存されているので、試験では表に出なかった。**Wi-Fiを一度も設定していない人は、USB中継を使えない**。直すにはコードの小さな変更が必要（U2bの「起動画面の改善」に含めていた項目）。USB中継を公開に含めないなら、必須ではない | `RadioDays_U2a3.ino` の `handleStart()`、`leaveSetup()` |
| A5 | **README（利用者向けの説明）を公開用に書き直す**（U4で技術的な記述を整備：対応環境、使い方、既知の制約。作品紹介と制作理念は作者と相談） | 今のREADMEの「現在の状態」はStage 3-3を指し、導入するファイルも3-3のまま。資料の多くは開発の記録で、利用者が読む手順（導入、操作、Macの中継の使い方、職場での注意、既知の制約）がまとまっていない | README |
| A6 | **公開する物の整理** | `firmware/` には途中の版が12個（導入してはいけない `RadioDays_2_0` を含む）あり、`.ino.bin` も多数。RADIODAYSのフォルダはgitの管理下にない。公開する版・ファイル・置き場所（リポジトリ、リリース）を決める | `firmware/`、`README` |
