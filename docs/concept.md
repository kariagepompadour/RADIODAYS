## 1. この作品は何か

RADIO DAYSは、単なるインターネットラジオではない。

**20世紀にBCLラジオやFM放送に夢中になった少年が、21世紀の技術を使って、かつて夢見た未来のラジオを作る。** それがRADIO DAYSである。

ダイヤルを回し、雑音の向こうから、世界のどこかの放送が浮かび上がってくる。検索して再生するのではなく、**探して、偶然出会う**。その体験を、手のひらの小さな機械で取り戻す。

## 5. 設計に生かすこと

コンセプトは、次の判断の基準になる。

| 原則 | 具体的には |
| --- | --- |
| **探す楽しさを奪わない** | 検索して再生するだけのアプリにしない。AUTOで便利に、MANUALで雑音の中を探す（Stage 2-3） |
| **雑音も作品の一部** | 局と局の間の「ザーッ」という音は、作者が「この感じ好きです」と確かめた音色（2026-10-20） |
| **昭和のオーディオ機器の手ざわり** | 大きな周波数表示、目盛りと指針、LEDレベルメーター（Stage 2-4）、時計とムーンフェイス（構想） |
| **世界とつながる** | Locationと地球儀で、世界各国の放送局を探すラジオへ（構想） |
| **本物の周波数への敬意** | 実在のFM局には、できるだけ実際の周波数を使う。ネット専用局には、RADIO DAYS独自の仮想周波数を割り当て、実在のものと区別する（構想） |
| **再生の安定がいちばん** | どんな演出も、ラジオとして聞けることを損なわない |
