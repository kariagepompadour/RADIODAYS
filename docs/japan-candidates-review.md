## 1. 調べ方と、事実と推測の分け方

| 区分 | 内容 |
| --- | --- |
| 局の一覧 | 公開の局データベース Radio Browser の日本の240件（2026-10-22）。そのうち `http://` のMP3は37件（重なりを含む） |
| **接続の確認**【接続】 | このMacから各URLに接続し、HTTPの応答、MP3のフレーム（ビットレート、サンプリング周波数）、配信が名乗る名前（ICYの見出し）を読んだ。**Cardputerでの再生は未確認** |
| **公式の配信の確認**【公式】 | 局・事業者の公式サイトで、そのURL（または同じ配信サービス）を案内しているかを見た |
| **利用条件**【条件】 | 公式サイトに利用条件・ライセンスの記載があるかを見た。記載がないものは「記載なし」とし、問題がないとは扱わない |
| 推測 | 【推測】と書く |

RADIO DAYSの条件：`http://` のMP3、192kbps以下（作者の方針）。USB中継では、URLがIPアドレスのもの（`http://65.21.…`）は中継の安全の決まりで受け付けない（Wi-Fiでは再生できる見込み）。

## 5. 比較とおすすめ

| | 局 | 区分 | 理由 |
| --- | --- | --- | --- |
| 1 | **湘南ビーチFM**（今） | 放送局（地域・音楽） | 音楽中心で聴きやすい地域局。配信が局名を名乗る |
| 2 | **FM世田谷**（新） | 放送局（地域・東京） | 東京の地域局。公式サイトが同じ配信サービスのプレーヤーを案内しており、配信元が公式と考えられる。都市の生活感がある |
| 3 | **FMかほく**（今） | 放送局（地域・北陸） | 地方の小さな局の手ざわり。演歌・歌謡曲も流れる |
| 4 | **OTTAVA**（今） | ネット局（クラシック） | 知られたネット局。配信元の確認を条件に |
| 5 | **City Pop One**（新、条件付き） | ネット局（シティポップ） | 昭和のシティポップはRADIO DAYSの雰囲気に合う。**公式と確認できる `http://` のURLが見つかることが条件** |

次の候補：Moon Mission Recordings（電子音楽）、Jazz Sakura（ジャズ）、AFN Tokyo（歴史的な個性。配信元の確認が必要）。

**組み立ての例**（決めるのは作者）：地域局3（湘南ビーチFM、FM世田谷、FMかほく）＋音楽のネット局2（OTTAVA、City Pop One または Jazz Sakura）＋環境音1〜2（大槌、山中湖）。日本のLocationは7局のままでも、局の数を変えても、U6からの「局の数で一周の長さが決まる」ダイヤルはそのまま使える。

## 6. 今後の確認（入れ替えを決める前に）

1. FM世田谷・湘南ビーチFM・FMかほく・OTTAVAに、このURLで聴くことや機器で受信することについて問い合わせる（どの局も公式サイトに利用条件の記載がない）
2. City Pop Oneに、`http://` で聴けるURLがあるか問い合わせる
3. サイバーフォレストのCC BY-NC-SA 4.0の条件（出典の表示、非営利）をREADMEにどう書くか決める
4. 環境音を日本に2つ置くか、WORLDなど別のLocationに置くか
