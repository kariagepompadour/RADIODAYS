## 2. 選んだ理由として記録から確かめられること

- `stations.md`（Stage 3-1）：各局の形式、都市、備考（例：「コミュニティFM（局名に78.9）」「WRN経由。正式な配信かどうかは未確認」「サイバーフォレスト。海辺の環境音のライブ配信」）。**局ごとの選んだ理由（なぜこの局か）は書かれていない**
- `stage-2-4.md` 6.4節（Stage 2-4の調査）：radikoとNHK（らじる★らじる）は「今の方式では再生できない」見通し、コミュニティFMと日本の音楽のネットラジオは「1局ずつ確かめれば候補になる」「いちばん追加しやすい」と書かれている
- 記録から言えるのは、**「RADIO DAYSで再生できる形式（`http://` のMP3）で、接続して確かめられた局」から選んだ**こと。それ以上の理由（好み、選考の基準など）は記録になく、ここでは推測しない

## 3. 一般的な日本のラジオ局との比較

| 局 | 主な聴き方（インターネット） | RADIO DAYSで |
| --- | --- | --- |
| NHKラジオ第1・第2・NHK FM | NHKの「らじる★らじる」（アプリ、ウェブ）、radiko | 配信はHLS（小分けにした配信）【総務省の資料、第三者の記事】、HTTPS【第三者の記事にあるURLの例】、48kbps【総務省の資料】。**今の方式では再生できない** |
| TOKYO FM、J-WAVE、TBSラジオ、文化放送、ニッポン放送 | radiko（アプリ、ウェブ）。聴ける地域は位置で判定される【報道】 | radikoはHLSで配信【報道】。**今の方式では再生できない**。直接再生できるMP3のURLの公開は、今回見つからなかった |

- 今の7局は、全国的によく知られた国内向けの局を含まない。知名度のある名前はNHK（ただし国際放送）だけ
- その代わり、地上波のコミュニティFM 2局、知られたインターネット局1局（OTTAVA）、日本の音楽のネット局2局、環境音1局と、**種類はばらけている**
- **「マニアックに感じる」理由の大部分は、技術的な制約**：よく知られた局はradikoやらじる★らじる（HLS・HTTPS・AAC）で配信され、RADIO DAYSが再生できる「`http://` のMP3」を公開していない。そのため、再生できる局を探すと、Icecast・SHOUTcastでMP3を出している小さな局やネット局が中心になる（今回の調査と、Stage 2-4の見通しが一致）

## 6. 今後の改善案（決めるのは作者）

1. **配信元の確認を先に**：OTTAVA、J1 Gold、NHK WORLD (WRN)、Japan Hits の配信が、それぞれの事業者の正式なものか確かめる（公開前の確認 A2 の一部）
2. **組み合わせの考え方**：「地域局（湘南ビーチFM、FMかほく）」「音楽（OTTAVA、日本の音楽のネット局）」「個性（大槌の環境音）」は今もそろっている。足りないのは「よく知られた局」だが、技術と利用条件の制約で、国内の主な局を直接入れるのは難しい
3. **よく知られた局の代わり**：MP3を公開しているコミュニティFMの中から、都市部や知名度のある局を探す（1局ずつ、配信元と利用条件を確かめる）
4. **説明で補う**：READMEなどに「日本の主な局はradiko・らじる★らじるの専用の配信のため、RADIO DAYSでは聴けない。代わりに、MP3で配信している地域局やネット局を選んでいる」と書くと、初めての人にも選局の理由が伝わる
5. 局の追加・入れ替えは、作者の判断の後に別の作業として行う
