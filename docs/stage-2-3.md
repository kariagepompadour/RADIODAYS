## 1. 変更内容

| 項目 | 内容 |
| --- | --- |
| 仮想周波数 | 各局にRADIO DAYS独自の周波数を割り当てた（`stations.h`）。内部では0.1 MHz単位の整数で扱う（802＝80.2 MHz）。重複・範囲外・並び順の誤りは、ビルド時に `static_assert` で検出する |
| AUTOモード | Stage 2-2と同じ。回すと次・前の局の周波数へ飛ぶ。最後の局の次は最初の局 |
| MANUALモード | 1クリックで0.1 MHz。局の周波数と一致したときだけ、その局につなぐ。局のない周波数では受信ノイズを鳴らし、局名は出さない。目盛りの端（80.0／90.0）で止まる |
| モード切り替え | `A` キーで AUTO ⇄ MANUAL。起動時は毎回AUTO（保存しない） |
| 画面 | 大きな周波数表示（7セグメント風の数字）、目盛りと指針、局の位置の印、AUTO／MANUAL、局名、状態、音量、Wi-Fi |
| ノイズ | 再生用タスクの中で作り、ストリームと同じ出力に流す（第4節） |
| 変えていないもの | Wi-Fi設定、NVSの保存方式、U135の押下・回転の判定（Stage 2-2と同じコードであることを確認） |

**仮想周波数の割り当て**

| 周波数 | 局 |
| --- | --- |
| 80.2 MHz | Radio Paradise（USA） |
| 82.6 MHz | FIP（France） |
| 85.1 MHz | KEXP（USA） |
| 88.7 MHz | BBC World Service（UK） |

目盛りの範囲は80.0〜90.0 MHz（100クリック）。

## 2. 操作

| 操作 | AUTO | MANUAL |
| --- | --- | --- |
| 回す | 次・前の局 | 0.1 MHzずつ |
| 押しながら回す | 音量 | 音量 |
| 短く押して離す | ミュート／解除 | ミュート／解除 |
| `A` | MANUALへ | AUTOへ |
| `,`・`/`（または `P`・`N`） | 前・次の局 | 0.1 MHz下げる・上げる |
| `;`・`.` | 音量 | 音量 |
| `M` | ミュート | ミュート |
| `W` | Wi-Fi設定 | Wi-Fi設定 |

**モードを切り替えたときの引き継ぎ**

- AUTO → MANUAL：周波数はそのまま。再生中の局はそのまま聞こえ続ける
- MANUAL → AUTO：局の周波数にいればそのまま。局の間にいれば、いちばん近い局の周波数に移り、0.35秒後にその局につなぐ

## 3. 接続と再生の安定性

| 場面 | 動き |
| --- | --- |
| 局の周波数で止まる | 0.35秒止まってから、その局に1回だけ接続を要求する（Stage 2-2の仕組み） |
| MANUALで局の周波数から外れる | **すぐに**ノイズを要求する。放送は止まり、局を外れたまま流れ続けることはない |
| MANUALで速く回して局を通り過ぎる | 局の上にいる時間が0.35秒未満なら、つながない。ノイズの要求は、すでにノイズなら送り直さない |
| 同じ局に戻る | つなぎ直さない |
| 局の周波数で接続中・バッファ中 | 音は出ない（ノイズも止まる。第6節） |

## 4. ノイズの作り方

| 項目 | 内容 |
| --- | --- |
| 作る場所 | **再生用タスク（デコード用タスク）の中。** スピーカーに音を渡すのは、このタスクだけ。ストリームとノイズは同時に鳴らず、切り替えるときは、前の音を出し切ってから次の音を始める |
| 方式 | 擬似乱数の白色雑音を、簡単なローパスフィルタで和らげたもの。22,050 Hz |
| 大きさ | 実効値で約−25 dBFS、最大でも約−15 dBFS（フルスケールの約19%）。テストで測定。放送の音より小さい |
| 音量・ミュート | スピーカーの音量（`M5.Speaker.setVolume`）がそのまま効く。ミュート中は無音 |
| メモリ | 新たなバッファは使わない（ストリームと同じ出力の3つのバッファを使う）。状態は8バイトだけ |
| ネットワーク | 不要。Wi-Fiが切れていてもノイズは鳴る |

## 5. 画面

```text
RADIO DAYS        MANUAL
        88.7 MHz              ← 大きな7セグメント風の数字
  ▪   ▪     ▪       ▪          ← 局の位置（アンバー）
──┴───┴───┴───┴───┴──         ← 0.5 MHzごとの目盛り
  80  82  84  86  88  90
              ▲                ← 指針（赤）
     BBC World Service         ← 局の周波数のときだけ
PLAYING               VOL 25%
WiFi -55dBm 120K     A:AUTO/MAN
```

- 曲名（放送局が送るもの）は、この画面には表示しない。シリアルに `[ICY] …` として出す。Stage 3で画面に戻す
- 状態の表示：局のない周波数では「NO STATION」。局の周波数で接続を待つ間は「TUNING...」。その後「CONNECTING」「BUFFERING」「PLAYING」

## 7. 静的テスト（Mac上、スケッチから取り出したコードで実行）

13項目すべてに合格した。

| # | テスト |
| --- | --- |
| 1 | AUTO：時計回りで80.2→82.6→…→88.7→80.2（循環）、反時計回りで80.2→88.7 |
| 2 | AUTO：止めてから0.35秒後に、要求が1回だけ出る |
| 3 | AUTO：0.35秒以内に元の局へ戻すと、要求が出ない |
| 4 | AUTO→MANUAL：周波数がそのまま |
| 5 | MANUAL：局から0.1 MHz外れると、すぐにノイズの要求が出る |
| 6 | MANUAL：局に戻っても、0.35秒たつまでは要求が出ない |
| 7 | MANUAL：局で0.35秒止まると、その局の要求が出る |
| 8 | MANUAL：81.0から84.0まで速く回して82.6を通り過ぎても、局への要求もノイズの重ねての要求も出ない |
| 9 | MANUAL：82.6で止めると、その局の要求が1回だけ出る |

## 10. 未確認事項と、実機テストで注意する点

| 項目 | 内容 |
| --- | --- |
| 実機での動作 | Stage 2-3は一度も実機で動かしていない |
| ノイズの音質と大きさ | 計算では放送より小さいが、ADVのスピーカーでの聞こえ方は未確認。大きすぎる・小さすぎる場合は `NOISE_LEVEL`（8000）で調整する。**最初は音量を小さくして試す** |
| ノイズから放送への切り替え | 接続とバッファの間（1〜3秒）は無音になる。違和感がある場合は、Stage 3でこの間もノイズを鳴らす方法を検討する |
| 7セグメント風フォント（Font7） | 小数点の表示と、文字の位置は実機で確かめる |
| 画面の配置 | 目盛りの数字、指針、局名が重ならないかは実機で確かめる |
| MANUALの回しやすさ | 局と局の間が最大3.6 MHz（36クリック）ある。U135の1回転あたりのクリック数によっては、回す量が多いと感じる可能性がある |
| 曲名 | 画面には出さない（シリアルのみ） |
| 「MHz」の表示 | 作者の要望で表示する。周波数はRADIO DAYS独自の仮想のもので、実際の放送とは関係ない（設計書 5.1節を更新） |
