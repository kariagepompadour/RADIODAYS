## 1. できること

| 機能 | 内容 |
| --- | --- |
| Wi-Fi | 本体のキーボードでネットワークを選び、パスワードを入れて接続する。**接続に成功したときだけ**NVS（名前空間 `radiodays`、キー `wifi`）に保存する。切れたら5秒から最大60秒の間隔で再接続する |
| 再生 | HTTPのMP3放送を受信し、内蔵スピーカー（イヤホンを挿せばイヤホン）で再生する。最初の局はRadio Paradise。開けない局は自動で次の局へ移る（4局、`stations.h`） |
| 音量 | U135を回す。起動するたびに小さい音量（48／255）から始まり、上限は192／255 |
| ミュート | U135を短く押して離す。ストリームは止めないので、解除するとすぐに音が戻る |
| 画面 | 局名・国名、曲名（放送局が送る場合）、状態（接続中・バッファ中・再生中など）、音量、Wi-Fiの電波の強さ、空きメモリ |
| エラー時 | 止まらずに状態を表示する（「WAITING FOR WI-FI」「UNAVAILABLE - NEXT」「NO STATION - RETRY」「NOT ENOUGH MEMORY」） |

最終的なUI（目盛りと指針のダイヤル）との関係：画面の上半分（局名の下）は、Stage 3でダイヤルに置き換える場所として空けてある。Stage 3では、ただ回す操作を選局に、押しながら回す操作を音量にする（設計書 第4節）。Stage 2-1では、どちらの回し方でも音量が変わる。

## 3. 静的確認の結果

| 確認したこと | 結果 |
| --- | --- |
| RADIO DAYSのNVS操作 | 起動時は `nvs_open`（読み取り専用）、`nvs_get_blob`、`nvs_get_stats` だけ。書き込みは `nvsWriteWifi()` の1か所だけで、Wi-Fi設定画面で接続に成功したときにしか呼ばれない。値が変わっていなければ書かない。空きエントリが32未満なら書かない。消去の処理はない |
| 起動画面 | キーかノブを押すまで、Wi-Fiを始めず、NVSにも書かない |
| Wi-Fiドライバー | 最初の `WiFi.mode()` より前に `WiFi.persistent(false)` を呼ぶ。Arduinoコア3.3.9では、これで `esp_wifi_set_storage(WIFI_STORAGE_RAM)` が呼ばれる（`WiFiGeneric.cpp` 第299行付近）。`WiFi.disconnect()` は常に「消去しない」引数で呼ぶ |
| ライブラリによるNVSへの書き込み | **M5GFX** は、起動時に判定したボードの種類を名前空間 `M5GFX`（キー `AUTODETECT`）に保存する。保存されている値と違うときだけ書く（`M5GFX.cpp` 第1109行付近）。Media JogとSOUND TERRARIUMもM5GFXを使っているので、同じ値が保存済みの可能性が高い【推測】。RADIO DAYSの書き込み関数を通らない書き込みとして記録する |
| 他のライブラリ | M5UnifiedのIMUの補正値の保存は、IMUを無効にしているので呼ばれない。ESP8266AudioとM5CardputerにはNVSの処理がない |
| メモリ不足のとき | 局を開くためのオブジェクトは `new (std::nothrow)` で作り、作れなければ「開けなかった局」として次の局へ進む（止まらない） |

## 4. 実機への導入手順（Launcher 2.9.1）

**導入する前に確認すること**

1. `RadioDays_2_1.ino.bin` のSHA-256を確かめる：

   ```bash
   cd ~/Documents/GitHub/RADIODAYS/firmware/RadioDays_2_1 && shasum -a 256 -c SHA256SUMS.txt
   ```

   すべて `OK` になること。
2. PManで、FREEが**1,376,256 B（0x150000）以上**あること（作者の確認では、約4MBの連続した空きがある）
3. Media Jog、SOUND TERRARIUMの大事な設定を控えておく（念のため）

**導入**

1. LauncherのWi-Fiアップロード（WebUI）か、SDカードからの導入で、`RadioDays_2_1.ino.bin` を導入する。merged image、Arduino IDEの「書き込み」、esptoolは使わない
2. **「Need …」という画面が出たら、必ず「Cancel」を選ぶ**（既存のアプリが上書きされる選択肢が出るため）
3. 導入が終わると、Launcherが再起動してRADIO DAYSを起動する。Launcherのメニューでは、名前は `RadioDays_2_1`、領域の名前は `radiod` になる見込み（ファイル名から作られる）

**元に戻す**：電源を入れ直し、Launcherの起動画面でボタンを押してLauncherに入り、他のアプリを起動する。

## 5. 初回起動からラジオ再生までの操作

1. U135をGroveにつなぐ（電源を切った状態で。U135がなくてもキーボードで操作できる）
2. RADIO DAYSを起動する。**起動画面**に、保存されたWi-Fiの有無とU135の有無が出る
3. 何かキーを押すか、ノブを押す。保存されたWi-Fiがなければ、**Wi-Fi設定**に進む
4. ネットワークの一覧から、ノブか `;`（上）・`.`（下）で選び、`ok`（Enter）かノブを押す
5. パスワードを入力して `ok`。`del` で1文字消す、`tab` で表示と非表示を切り替える、`Fn`＋`esc`（`` ` ``）で一覧に戻る
6. 「Connected and saved.」と出たら、キーかノブを押す。ラジオの画面になり、「CONNECTING」→「BUFFERING」→「PLAYING」と変わって音が出る
7. 操作：ノブを回す＝音量、ノブを短く押す＝ミュート、`;`・`.`＝音量、`M`＝ミュート、`N`＝次の局、`W`＝Wi-Fi設定

2回目以降は、起動画面でキーかノブを押すと、保存したネットワークにつないで再生を始める。

## 6. 動作確認の項目

| # | 確認すること | 期待する結果 |
| --- | --- | --- |
| 1 | Launcherから導入できる | 「Need …」が出ずに導入できる。PManで、`radiod` が0x150000の大きさで作られている |

| 12 | 他のアプリ | LauncherからMedia JogとSOUND TERRARIUMを起動し、設定が残っている |
| 13 | シリアルの記録（任意） | USBシリアル（115200）に `[NVS] write #1 radiodays/wifi ...` が、接続に成功したときに1回だけ出る。`[STAT]` 行で空きヒープを確認できる |
