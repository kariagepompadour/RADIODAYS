# 日本の主要局（知名度を優先した場合）と、radikoの利用方法：調査と評価

- 作成日：2026-10-22
- 状態：**調査と評価だけ**。`stations.h`、U3〜U8、USB中継は変えていない。局の追加・削除・入れ替えもしていない
- その後の決定（2026-10-22）：**radiko対応は保留**。Cardputer自体を操作してラジオを楽しむことを大切にするため、PCのブラウザで公式のradikoを開き音をPCから出す方式（第3.2節の方式②）は、将来の選択肢として記録するだけにする
- 新しい選局の方針（作者とエドガー、2026-10-22）：①その国での知名度・人気・聴取の実績、②毎日聴きたくなる内容、③多様さ、④公式の配信と利用条件、⑤RADIO DAYSで再生できるか、の順に考える。HTTP MP3は絶対の条件ではない。環境音は今回の選定では優先しない
- 書き方：【資料】＝根拠の資料がある、【一般】＝広く知られていることだが今回資料で確かめていない、【推測】＝推測

## 3. radikoの利用について

### 3.1 radikoの利用規約（ユーザー規約、最終改定2025年10月1日）で確かめたこと【資料】

| 条 | 内容（要約） |
| --- | --- |
| 第1条 | サービスはradikoのソフトウェア（アプリ）で利用する。受信する機器は会社の仕様に合うもの |
| 第3条 | 自分の私的な聴取のため。放送の地域の外では、会社が認めた範囲（有料のエリアフリーなど）を除いて聴けない |
| 第4条(3) | 「本ソフトウェア」または会社が別に提供する方法以外で聴くことを禁止（地域外で聴けるアプリ、録音できるアプリを含む） |
| 第4条(2)(4)(5)(6)(7) | ソフトウェアの改変・解析、認証の解読・回避、公式の方法以外での復号、不正なアクセス、規約を超える利用を可能にする道具の開発を禁止 |
| 第13条 | NHKの番組はエリアフリーの対象外 |
| 埋め込みの規約 | ウェブサイトに公式の再生の部品を埋め込む方法がある（埋め込みのコードの規約） |
| 海外 | 規約は海外での利用を直接は書いていない。地域による制限があるので、日本の外では聴けないと考えられる【推測】 |

公式の聴き方は、公式アプリ（スマートフォン）、ウェブ（radiko.jp）、対応機器（スマートスピーカー：Amazon Alexa、Googleアシスタント、ソニーのスピーカーなど）【資料：報道・メーカーのページ】。

### 3.2 方式ごとの比較

| 方式 | 何をするか | 規約との関係 | 必要なもの | 評価 |
| --- | --- | --- | --- | --- |
| ① Cardputer単独でradiko | Cardputerがradikoの配信を受けて鳴らす | **第4条(3)(5)(7)に反する**（公式のソフトウェアでない方法での聴取・復号）。公式の対応機器になるには、radikoとの契約が必要と考えられ【推測】、個人の作品では現実的でない | ― | **×（行わない）** |
| ② PCで公式のradikoを鳴らし、Cardputerで局を選ぶ | Cardputerで局を選ぶと、PCの補助のスクリプトが公式のradikoのウェブ（例：`radiko.jp/#!/live/TBS`）をブラウザで開く。**音はPCから出る**。Cardputerは選局の表示（ダイヤル、局名、時計）を担う | 聴取は公式のウェブで行う（第4条(3)の「会社が提供する方法」）。補助のスクリプトは「ページを開く」だけで、配信の解析・復号・録音はしない。**ブラウザを外から操作することについて規約に直接の記載はない**ので、必要なら事前にradikoに確かめる【推測】 | PC（今の中継はmacOSだけ）、ブラウザ、radikoの地域（無料は住んでいる地域の局だけ、ほかの地域は有料のプレミアム）、ブラウザでのログイン（プレミアムの場合）。日本国内 | **○（正規の方法に沿う。検討の価値がある）** |
| ③ PCで受けた音をCardputerへ送る（今のUSB中継と同じ形） | PCがradikoを受信し、音をUSBでCardputerへ流す | 公式のソフトウェア以外での受信・復号、または録音・再送信にあたるおそれがある（第3条、第4条）【推測】 | ― | **×（行わない）** |

### 3.3 方式②で、今のUSB中継をどこまで使えるか（実装はしない）

| 部分 | 使えるか |
| --- | --- |
| USBシリアルのつながり（HELLO、中継が見つかったかの表示、id付きの要求、時刻） | **そのまま使える**。新しい要求（例：「radikoのこの局を開く」）を1種類足すだけ【推測】 |
| MP3を送る仕組み（TUNE→RDSYNC→クレジット） | 使わない（radikoの音はPCで鳴る） |
| 許可するホストの決まり | 使わない（中継がradikoに接続しないため。開くのは決めたradikoのページだけにする） |
| PC側に増えるもの | ブラウザを開く・タブを切り替える処理（macOSでは `open` か AppleScript。ブラウザの自動操作の許可が要る場合がある）。常駐は今の中継と同じ1つ（ターミナルで動かす） |
| Cardputer側に増えるもの | 局ごとの「radikoの局の識別名」（TBS、LFR、QRRなど）、選局したときに要求を送る処理、「音はPCから出ている」ことを示す表示。音は鳴らさない（局の間の雑音だけは鳴らせる） |

**注意（方式②）**
- 音はCardputerから出ない。机のPCのスピーカーやイヤホンで聴く形になり、「Cardputerがラジオ」という作品の形が少し変わる
- ブラウザが自動で音を鳴らし始めるとは限らない（自動再生の制限）。最初の1回はPCで再生のボタンを押す必要があるかもしれない【推測・未確認】
- 職場では、radikoの利用、ブラウザの自動操作、USB機器の利用が職場の規則に従う必要がある（これまでの職場の制約と同じ）
- 日本の外では使えない。日本のLocationに「radikoの局」と「どこでも聴けるMP3の局」を混ぜる設計が考えられる

## 4. 将来の技術対応の見通し（実装はしない）

| 対応 | 見通し |
| --- | --- |
| HTTPS・HLS・AACをCardputerで再生する | フラッシュの残り（U8で1,856 B）とメモリでは難しい。仮にできても、**radikoは規約上、公式以外のソフトウェアでの聴取ができない**。らじる★らじるの今の利用規約は今回確認できなかった（2011年の資料では国内向け・無料） |
| 方式②（PCで公式のradiko・らじる★らじるを開いて操作する） | 技術的には今のUSBのつながりに小さく足せる見込み。規約上もっとも無理がない。ただし音はPCから出る |
| radikoの対応機器になる | 契約が必要と考えられ、個人の作品では現実的でない【推測】 |

## 5. 知名度を優先した日本のラインナップの例（参考。決めるのは作者）

| 枠 | 候補 | 聴く方法 |
| --- | --- | --- |
| 公共放送 | NHKラジオ第1、NHK-FM | らじる★らじる（方式②）または radiko（方式②、地域による） |
| AM（東京） | TBSラジオ、ニッポン放送、文化放送 | radiko（方式②） |
| FM（東京） | TOKYO FM、J-WAVE | radiko（方式②） |
| 関西 | MBSラジオ、ABCラジオ、FM802 | radiko（方式②）。関西の外では有料のエリアフリーが必要 |
| ネット局 | OTTAVA（今も再生できる）、超！A&G+ | OTTAVAは今のRADIO DAYSで再生できる |
| 国際 | NHK WORLD-JAPAN | 今のURL（公式は未確認） |

**結論**
- 知名度を優先すると、日本の局の大部分はradiko（またはらじる★らじる）の局になる。どれも、**Cardputer単独では規約上も技術上も聴けない**
- 正規の方法で聴くには、**PCで公式のradiko・らじる★らじるを鳴らし、Cardputerを選局と表示の装置にする方式②**がもっとも現実的。今のUSBのつながりを使えるが、音はPCから出る
- 今のRADIO DAYS（Cardputerから音が出る）で聴ける日本の主要な局は、OTTAVAとNHK WORLD（WRN、公式は未確認）くらいしかない

## 6. 作者に決めていただきたいこと

1. 方式②（音はPCから、Cardputerは選局と表示）を、日本の主要局のために検討を進めるか
2. 進める場合、radikoに「ブラウザで公式のページを開く補助」を事前に問い合わせるか
3. 日本のLocationを「radikoの局（PCと日本国内が必要）」と「どこでも聴けるMP3の局」の混ぜ方にするか
4. 大阪・名古屋の局の知名度の根拠（聴取率）を、さらに探すか
