## 1. できること

### 1.1 Location（Stage 3-1）

- **JAPAN／USA／UK／FRANCE／WORLD** の5つ。局は各5〜7局（[stations.md](stations.md)）
- `L` キーでLocation画面を開き、ダイヤルで選び、押す（または `ok`）とそのLocationの局に切り替わる。`esc`（`` ` ``）で、何も変えずに戻る
- 選んでいる間も、今の局は鳴り続ける。切り替えるときは、再生用タスクが今の局を閉じたのを確かめてから、新しい一覧に切り替える
- 切り替えた後は、そのLocationの最初の局の周波数から始まる。AUTO／MANUAL、ノイズ、メーター、ミュート、音量はそのまま
- 選んだLocationはNVSに保存し、次の起動時に戻す（第3節）
- 画面の最下行の左端に、今のLocationを表示する

## 3. NVS（保存）

| キー | 内容 | 書き込むとき |
| --- | --- | --- |
| `wifi`（既存） | Wi-Fi | **変更なし**（コードがStage 2-4と同じであることを確認） |
| `loc`（新規） | Location（番号と名前、magic・版・CRC付き、20バイト） | Location画面で、**違うLocationに切り替えたときだけ**。同じ内容なら書かない。空きエントリが32未満なら書かない |

- 起動時は読むだけ。記録が壊れている、新しい版である、読めない、のいずれかの場合は、上書きしない（その起動の間だけ選んだLocationを使う）
- Locationの並びが将来変わっても、名前で探し直すので、別のLocationに入れ替わらない
- 時計と月は、NVSに何も書かない

## 4. 音声への影響を避けるために

- 再生用タスクの変更は、局の一覧を「今のLocationの一覧」から読む形にしたことと、番号の範囲を確かめる処理だけ（Stage 2-4との差分で確認）
- U135の判定、ノイズの生成、メーターへの入力、Wi-Fi、Wi-Fiの保存のコードは、Stage 2-4と同じ（差分で確認）
- Locationの切り替えは、再生用タスクが「止まった」合図を出してから行う。10秒たっても合図がない場合も切り替えるが、局の一覧はすべてプログラムに固定されていて消えることがなく、番号は範囲を確かめてから使うので、壊れたデータを読むことはない
- 地球儀と時計の描画は、画面のタスク（コア1）で行う。止まっているときは描かない
